# Copy

When adding strings, add both `EN` and `FIL` keys in `src/i18n.ts`.

Filipino should sound like how people actually talk in 2026: short, casual, mixed with English words everyone already uses (login, diesel, score, skip, QR, SOS).

Do not use deep or literary words. Prefer:

- huwag muna (not huwag umalis sa laot in a poem)
- sulit / lugi / kita
- alon, hangin, ulan
- Go ka / Ingat / STAY

Keep GO, CAUTION, STAY as codes. Translate the sentence around them.

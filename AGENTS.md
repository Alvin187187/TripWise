# TripWise

React + Vite + Tailwind CSS v4. Phone-first fishing decision app.

A Vite dev server may already be running (default 8443). Hot reload applies to `src/`.

## Start here

- `src/App.tsx` — screens
- `src/live.ts` — weather, diesel, score
- `src/ledger.ts` — trips and money
- `src/i18n.ts` — English / Filipino
- `src/index.css` — theme

Workspace steering, specs, and hooks live in `.kiro/`.

## Conventions

- Default-export screens.
- Double quotes when a string contains an apostrophe.
- Keep GO / CAUTION / STAY honest. STAY means do not leave.
- Put new user-facing copy in `src/i18n.ts`.

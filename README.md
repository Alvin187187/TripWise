# TripWise

Worth the fuel. Safe home.

TripWise is a phone web app for small-scale fishers in Navotas / Manila Bay. It reads the sea, diesel, and your last trips, then returns **GO**, **CAUTION**, or **STAY**.

Built with Kiro. Product specs, steering, and hooks are in `.kiro/`.

## Run

```bash
pnpm install
pnpm dev
```

## Stack

React 19, Vite 8, TypeScript, Tailwind CSS v4, MapLibre GL. Live weather from Open-Meteo. Gale and diesel from public PAGASA and DOE pages.

## Privacy

Catch logs and profile stay in the browser. They are not in this repository.
